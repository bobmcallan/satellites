mcp

Satellites exposes the substrate verbs over MCP (Model Context Protocol) JSON-RPC. Agents attach via the endpoint below; the CLI calls the same verbs locally and shares its implementation with the MCP transport.

ENDPOINT
POST /mcp
TRANSPORT
Streamable HTTP (per MCP spec)
AUTH
Authorization: Bearer <api-key>
CONTENT
application/json JSON-RPC 2.0

example

curl -X POST {{.ExampleURL}}/mcp \
  -H 'Authorization: Bearer {{.ExampleKey}}' \
  -H 'Content-Type: application/json' \
  -H 'Mcp-Session-Id: <session-id>' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

The streamable HTTP transport requires an Mcp-Session-Id header after the initial handshake. Use an MCP client (Claude Code, Warp, Gemini CLI, Codex) for the full session lifecycle.
